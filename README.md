# makonote-forest

Static website for Tomakama Tech app pages.

Published at:

https://apps.tomakamatech.com/

## Contents

- CopyPouch product page
- CopyPouch Pocket product page
- Guides
- Support pages
- Privacy policies

## Development

The public site is served from the `docs/` directory.

After editing pages, check:

- Page links and language switch links
- SEO metadata such as `description`, `canonical`, and `hreflang`
- `docs/sitemap.xml`
- `docs/robots.txt`

## Deployment

GitHub Pages publishes the `docs/` directory to the custom domain.
